Two numbers, on purpose

Backup size next to source size

Most tools show you one or the other. Shown together they answer questions neither can answer alone.

  • What deduplication and compression are saving you. A 758 GB source occupying 814 GB at the destination is telling you something quite different from one occupying 300 GB - and only the pair reveals it.
  • Whether a destination is about to fill up. Source growth and destination growth are not the same curve, and the one that matters for "will this fail next month" is the destination.
  • Whether versioning is running away. A destination growing much faster than its source usually means a retention policy that is keeping more than you meant.
Active Backup

Active Backup for Business

A header with the device and task count, then the repository size, then the devices themselves.

Backup size

  • The total deduplicated size of the repository, per volume.
  • Broken down by workload - PCs, servers, virtual machines and DSM devices - each with its own device count and size.
  • Labelled as what it is: deduplicated size on the destination, as reported by Active Backup. Not a sum of source sizes dressed up as one.

Devices

  • Each protected device with its address and operating system.
  • Last backup, or Never when it has not run - which is the entry worth noticing.
  • Backup Now per device.
When something fails

You find out without looking

  • The task says so on its card, with the state the NAS reported.
  • The home screen's health badge reflects it, so a failed backup surfaces on the first screen you see rather than three taps in.
  • A device that has never been backed up is shown as Never rather than as a blank or a zero - those would read as "fine".
What the app will not do: create or edit a backup task, change a retention policy, or restore from a backup. Those are Hyper Backup's own job, and a restore in particular is not something to start by accident on a phone.
Common questions

Backup FAQ

Can I start a backup from my phone?
Yes. Every Hyper Backup task has a Run Now button, and a running task shows a live progress bar you can cancel.
What is the difference between backup size and source size?
Source size is how much data the task is backing up. Backup size is how much space it actually occupies at the destination, after deduplication and compression. Seeing both together shows what those are saving you, and whether a destination is filling faster than its source is growing.
Does it show Active Backup for Business?
Yes - the deduplicated repository size broken down by workload, each with its device count, plus every protected device with its last backup time and a Backup Now button.
Will it tell me if a backup failed?
Yes. Task state is shown per task, and a failed task also raises the health badge on the home screen.
Can I restore from a backup in the app?
No. Restores are done in Hyper Backup or Active Backup, where the version picker and the target selection live. The app monitors and triggers backups; it does not put data back.
