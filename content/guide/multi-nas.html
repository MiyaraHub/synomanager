Multiple NAS devices

One app, every DiskStation

Add as many as you like. Each keeps its own credentials, its own dashboard layout and its own settings, so the backup target in the garage does not have to look like the media server in the lounge.

The device list

What each entry shows

Reached from Settings › Manage NAS Devices, or as the screen the app opens on when you have more than one and have set it to ask.

  • Nickname and address - your name for it, and the host and port it connects on.
  • Chips for the things worth seeing without opening the form: whether it is HTTPS, which port, and which account it signs in as.
  • Connected when it is the active one.
  • Connect to switch to it, and Wake to send it a magic packet if it is asleep.
  • A drag handle - reorder the list so the one you use most is at the top.
The overflow menu

Five things you can do to an entry

ActionWhat it does
RenameChanges the display name only - the app's label for it. The NAS's own server name is untouched; that lives in DSM's Control Panel.
Change IPA shortcut for the field that changes most often - the address and port - without walking the whole form.
Edit ConfigurationThe full form: HTTPS, certificate verification, credentials, two-factor authentication and the camera live-view tunnel.
Test ConnectionChecks reachability without changing anything, and distinguishes "cannot reach it" from "reached it and the credentials were refused".
Remove NASDeletes the entry and its stored credentials from the app. Nothing on the NAS is touched.
What is per-NAS

What each device remembers on its own

Per NAS

  • Credentials and the 2FA device token.
  • Which dashboard cards are on, and their order.
  • Which cards are collapsed.
  • Which sub-views are hidden in each tab, and their order.
  • The camera live-view tunnel setting.

App-wide

  • Theme, surface, accent and text size.
  • The bottom navigation bar.
  • Polling interval and temperature unit.
  • Launch behaviour.
  • Which help cards you have dismissed.
The same NAS twice is a legitimate setup. One entry by local IP for home, one by QuickConnect for away. They are separate entries with separate layouts, and switching takes one tap.
Common questions

Multi-NAS FAQ

How many NAS devices can I add?
As many as you like. Each keeps its own credentials, dashboard layout, card order and collapse state.
Does renaming a NAS change anything on the NAS itself?
No. Rename changes the display name in the app only. To change the NAS's own server name, use DSM's Control Panel.
What is the difference between Change IP and Edit Configuration?
Change IP is a shortcut for the address and port. Edit Configuration opens the whole form, including HTTPS, certificate verification, credentials, 2FA and the camera tunnel toggle.
What happens when I remove a NAS?
The entry and its stored credentials are deleted from the app. Nothing on the NAS is touched.
Which one does the app open on?
Whatever you set in Launch Behavior - the device picker, the last one you used, or always a specific one.
