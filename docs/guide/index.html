Syno Manager User Guide

Everything the app does, screen by screen and control by control - including the things it deliberately will not do, and why. Every screen

The tabs, in order

The bottom bar holds up to nine tabs plus More. Each tab is a group of sub-views you can reorder or hide.

System

Storage

Volumes & Pools, Disk Health and External. RAID type, free space, SMART per drive, Quick SMART Test and safe eject.

Network

Throughput, Connections, Services, VPN and DDNS with your public address.

Files

File Station, Shared Folders, Note Station, Synology Office and Contacts.
